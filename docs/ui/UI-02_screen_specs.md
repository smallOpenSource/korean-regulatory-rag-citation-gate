# UI-02 Screen Specs

## Dashboard
- 위젯: 긴급 후속 조치 건수, 7일 이내 만기 고객 수, 오늘 예정 상담, 최신 하우스뷰 요약.
- 빠른 이동: 후속 조치 관리함 이동, 고객 목록 이동.

## Customer List
- 컬럼: 고객명, 세그먼트, 위험등급, 담당 PB, 최종 접촉일, 미완료 후속 조치 수.
- 필터: 세그먼트, 위험등급, 미접촉 기간, 만기 임박.
- 정렬: 미접촉 기간 내림차순 기본.

## Customer 360
- 섹션:
  - 프로필: 세그먼트, 위험등급, 총자산, 담당 PB.
  - 포트폴리오 요약: 자산배분 도넛 차트, 연초 이후 수익률, 하우스뷰 대비 격차.
  - 진행 중인 후속 조치: 미완료 후속 조치 카드 목록.
  - 사후관리 이벤트: 진행 필요 이벤트 목록.
  - 최근 상담: 최근 5건.
- AI 브리핑 패널: consultation_briefing 에이전트 결과 + AI 생성 표기.

## Consultation Workspace
- 왼쪽 패널: 고객 360 요약, 활성 하우스뷰 참조, 포트폴리오 격차 차트.
- 본문: 상담 노트 에디터, 체크리스트(적합성 확인 + 설명의무 확인).
- 오른쪽 패널: AI 브리핑, 후속 조치 스크립트, 이메일 초안 생성.
- 추천/주문 시뮬레이션 패널: 상품 선택, 4-gate 상태, 차단/승인 사유, “실제 주문 아님” 배지 표시.
- 완료 버튼: 적합성 확인과 설명의무 확인이 모두 참일 때만 활성화.

## 후속 조치 관리함
- 카드 목록: 우선순위 순 정렬(긴급 → 높음 → 보통 → 낮음).
- 카드 내용: 고객명, 업무 유형, 발생 사유, 기한, 스크립트 토글.
- 액션: 진행 시작, 완료, 보류, 해당 없음.

## House View Detail
- 헤더: 기간, 상태, 버전, 활성화일.
- 요약 문구.
- 자산 관점 표: 자산군, 투자 의견(비중 확대/중립/비중 축소), 근거.
- 모델 포트폴리오: 안정형 / 균형형 / 성장형 배분 막대 차트.
- 핵심 위험 목록.
