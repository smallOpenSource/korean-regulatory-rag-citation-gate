# UI-03 State Transitions

## Consultation Status Flow
```
[신규 상담 생성] → 초안
초안 → [저장] → 저장됨
저장됨 → [적합성 확인 + 설명의무 확인 + 컴플라이언스 통과] → 완료
초안 / 저장됨 → [삭제] → 물리 삭제 (완료 상담은 삭제 불가)
```

## 후속 조치 흐름
```
[배치 생성] → 대기
대기 → [PB 확인] → 진행 중
진행 중 → [완료] → 완료
진행 중 → [보류] → 보류 (보류 해제 시각 설정)
보류 → [기한 도래] → 진행 중 (자동)
대기 / 진행 중 → [해당 없음] → 해제
완료 / 해제 → (재활성화 불가)
```

## House View Flow
```
[운영자 생성] → 초안
초안 → [검토 요청] → 검토 대기
검토 대기 → [활성화] → 활성 (기존 활성 하우스뷰 → 대체됨)
활성 → [신규 활성화] → 대체됨 (자동)
대체됨 → [보관] → 보관
초안 / 검토 대기 → [폐기] → 보관
```

## Email Draft Flow
```
[AI 생성] → 초안
초안 → [PB 승인] → 승인
승인 → [발송] → 발송
초안 / 승인 → [취소] → 취소
```

## UI Behavior Rules
- 상태 전환 불가 버튼은 disable (숨김 처리 금지).
- 완료 상담은 노트 추가만 가능, 기존 내용 수정 불가.
- 활성 하우스뷰가 없으면 상담 생성 시 경고 표시.


## Recommendation Simulation Flow
```
[직원 생성] → 초안
초안 → [4-gate 하나 이상 실패] → 차단
초안 → [4-gate 모두 통과] → 승인
초안 / 차단 → [취소] → 취소
승인 → (수정 불가, 주문 시뮬레이션 생성 가능)
```

## Order Simulation Flow
```
[승인된 추천 기반 생성] → 초안
초안 → [4-gate 재검증 실패] → 차단
초안 → [4-gate 재검증 통과] → 승인
승인 → [시뮬레이션 실행 기록] → 모의 실행 완료
초안 / 차단 / 승인 → [취소] → 취소
```
