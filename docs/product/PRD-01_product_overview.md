# PRD-01 Product Overview

## Definition
Harness는 은행·증권사의 PB/WM 직원이 고액자산가 고객을 관리할 때 사용하는
**내부형 AI 업무 지원 서비스**다. AI는 의사결정 보조만 수행하고 최종 판단 책임은
직원과 소속 금융기관에 있다.

## Target Users
| 역할 | 주요 니즈 |
|---|---|
| Junior PB | 상담 브리핑, 후속 조치 스크립트, 규정 Q&A |
| Senior WM | 포트폴리오 격차 분석, 생애 이벤트 추적 |
| Branch Manager | 팀 KPI 모니터링, 미접촉·만기 현황 |
| Admin | 하우스뷰 승인, 배치 운영, 권한 관리 |

## Value Proposition
- 상담 준비 시간 단축 (브리핑 자동 생성)
- 하우스뷰 일관 적용 (격차 분석 자동화)
- 사후관리 누락 방지 (이벤트 기반 후속 조치)
- 컴플라이언스 부담 감소 (체크리스트 내장)

## Positioning
- 직원 전용 내부 도구 (고객 직접 접근 불가)
- AI 보조 서비스 (직접 투자자문 아님)
- 자본시장법상 투자자문업 등록 불요 범위로 설계
