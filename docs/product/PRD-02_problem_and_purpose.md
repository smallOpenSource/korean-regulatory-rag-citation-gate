# PRD-02 Problem and Purpose

## Problems
| 문제 | 현상 |
|---|---|
| PB 역량 편차 | 신입과 시니어 상담 품질 격차 큼 |
| 수작업 상담 준비 | 고객 파악에 30~60분 소요 |
| 하우스뷰 미적용 | 전사 뷰가 있어도 개인 판단으로 대체 |
| 사후관리 누락 | 만기·손실 이벤트 수기 관리 → 누락 빈발 |
| 설명의무 기록 번거로움 | 체크리스트 별도 작성 → 비효율 |

## Purpose
Harness는 고객 브리핑, 후속 조치, 하우스뷰, 사후관리, 규정 확인을 **하나의 화면 흐름**으로
통합해 업무 연속성과 상담 품질을 높인다.

## Success Criteria
정량 지표는 PRD-06을 참조한다.
