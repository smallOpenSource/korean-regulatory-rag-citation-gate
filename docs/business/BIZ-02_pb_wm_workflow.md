# BIZ-02 PB WM Workflow

## Lifecycle
1. 고객 발굴
2. 고객 성향 파악 (위험 성향 설문)
3. 포트폴리오 제안 (하우스뷰 기반)
4. 상품 설명과 판매 (설명의무 이행)
5. 정기 리뷰 (성과, 변동, 만기 확인)
6. 사후관리 (이벤트 기반 후속 연락)

## Harness Role per Stage
| 단계 | Harness 지원 기능 | 관련 화면 |
|---|---|---|
| 발굴 | 후속 조치 관리함(우선순위 고객 목록) | 후속 조치 관리함 |
| 성향파악 | 위험등급 확인, 적합성 경고 | 고객 360 |
| 제안 | 하우스뷰 요약, 포트폴리오 격차 분석 | 상담 워크스페이스 |
| 판매 | 설명의무 체크리스트, AI 브리핑 | 상담 워크스페이스 |
| 리뷰 | 성과, 연초 이후 수익률, 만기 알림 | 고객 360 |
| 사후관리 | 사후관리 이벤트, 후속 조치 자동 생성 | 후속 조치 관리함 |

## Standard Consultation Flow
1. 후속 조치 관리함에서 대상 고객 선택.
2. 고객 360에서 전체 현황 파악.
3. AI 브리핑 확인 (consultation_briefing 에이전트).
4. 하우스뷰 참조 + 포트폴리오 격차 분석.
5. 상담 노트 기록.
6. 적합성 확인 + 설명의무 확인 완료.
7. 필요 시 추천/주문 시뮬레이션 패널에서 4-gate 확인.
8. 후속 이메일 초안 생성(`POST /email-drafts`); 승인된 초안만 provider-gated `POST /email-drafts/{draft_id}/send`로 발송한다.
9. 상담 완료 전환.
